Chrome Dino Game

The Chrome Dino Game was released in 2014 by Google. It appears when users lose internet connection in Chrome.

Players control a dinosaur that jumps over obstacles and avoids enemies. It's simple, fun, and addictive.

Untitled Goose Game

Untitled Goose Game was released in 2019 by House House. It is a puzzle-stealth game about a mischievous goose.

Players complete tasks by bothering villagers, stealing objects, and causing funny problems around town.

Flappy Bird

Flappy Bird was released in 2013 by Dong Nguyen. It is a mobile game where players tap to keep the bird flying.

Players guide the bird between pipes. The game became popular because it was simple, difficult, and addictive.
